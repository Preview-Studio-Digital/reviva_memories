# Project Rules - Reviva Memories

## Git & Repository Policy
- **NO AUTOMATIC GIT COMMITS OR PUSHES**: Never run `git commit`, `git push`, or publish repository changes automatically.
- All modifications, creations, and file refactorings must remain **strictly local**.
- Only execute `git add`, `git commit`, or `git push` when the user **explicitly and directly requests** it in the conversation (e.g., "pode comitar", "envie para o git", "faça o push", "suba as alterações").
- **BRANCH ÚNICA E OBRIGATÓRIA: `main`**: Trabalhar, comitar e enviar alterações **SEMPRE e EXCLUSIVAMENTE na branch `main`**. É expressamente proibido criar ou alternar para branches secundárias como `feature/painel-dev`. A Cloudflare Pages depende unicamente da branch `main` para publicar as alterações em produção.

## Vocabulário & Terminologia Obrigatória
- **PROIBIDO O USO DA PALAVRA 'ATELIÊ'**: Nunca utilize o termo "ateliê" no código, na interface, em comentários ou na comunicação com o usuário. Refira-se sempre a **Produção**, **Painel de Produção**, **Estúdio** ou termos diretos equivalentes.
